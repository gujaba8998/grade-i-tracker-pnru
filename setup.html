📖 คู่มือการตั้งค่า Google Sheets Backend

ทำตามขั้นตอนนี้เพื่อให้ Admin ทั้ง 4 คนสามารถเข้าใช้งานได้พร้อมกันจากเครื่องไหนก็ได้

1
สร้าง Google Spreadsheet ใหม่
  1. เปิด sheets.google.com แล้วสร้าง Spreadsheet ใหม่
  2. ตั้งชื่อ เช่น "ระบบติดตามเกรด I 2568"
  3. คัดลอก Spreadsheet ID จาก URL:
    URL ตัวอย่าง: https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
    ส่วนที่ขีดเส้นใต้คือ Spreadsheet ID
2
เปิด Google Apps Script
  1. ใน Spreadsheet → คลิก Extensions (ส่วนขยาย) → Apps Script
  2. ลบโค้ดเดิมทั้งหมดออก
  3. วางโค้ดจากไฟล์ Code.gs ทั้งหมดลงไป
  4. แก้ไขบรรทัดนี้ด้านบนสุด:
    const SPREADSHEET_ID = 'REPLACE_WITH_YOUR_SPREADSHEET_ID';
    → เปลี่ยน REPLACE_WITH_YOUR_SPREADSHEET_ID เป็น ID จากข้อ 1
  5. กด Save (Ctrl+S)
3
รัน setupSpreadsheet() ครั้งเดียว
  1. ใน Apps Script Editor → คลิก dropdown เลือก function: setupSpreadsheet
  2. กดปุ่ม ▶ Run
  3. อนุญาต Permission ที่ขอมา (Allow)
  4. รอจนขึ้น "Execution completed" ใน Log
✅ ขั้นตอนนี้จะสร้าง Sheet ต่างๆ ให้อัตโนมัติ: students, examScores, users, log
4
Deploy เป็น Web App
  1. คลิก Deploy → New Deployment
  2. ประเภท: Web App
  3. ตั้งค่าดังนี้:
การตั้งค่าค่าที่เลือก
Execute asMe (ชื่อ Google account ของคุณ)
Who has accessAnyone
  1. คลิก Deploy
  2. คัดลอก Web App URL ที่ได้ (ขึ้นต้นด้วย https://script.google.com/macros/s/...)
⚠️ ทุกครั้งที่แก้ไข Code.gs ต้อง Deploy ใหม่ (New Deployment หรือ Deploy → Manage Deployments → Edit)
5
ใส่ URL ในแอปพลิเคชัน
  1. เปิด index.html → Login เป็น Admin
  2. ไปที่เมนู ⚙️ ตั้งค่าระบบ
  3. วาง Web App URL ที่คัดลอกไว้ในช่อง Google Apps Script URL
  4. กด บันทึก
  5. Banner สีเหลือง "Demo Mode" จะหายไป — หมายความว่าเชื่อมต่อสำเร็จ ✅
💡 แต่ละเครื่องต้อง Paste URL ด้วยตัวเอง (เก็บใน Browser) แต่ข้อมูลทั้งหมดจะ Sync กันผ่าน Google Sheets
6
แชร์ไฟล์ให้ทีม Admin
  1. วาง ทุกไฟล์ในโฟลเดอร์ grade-tracker/ ไว้ใน Google Drive โฟลเดอร์เดียวกัน
  2. แชร์โฟลเดอร์ให้ Admin ทั้ง 4 คน
  3. Admin แต่ละคน: ดาวน์โหลดไฟล์ → เปิด index.html → ใส่ URL → พร้อมใช้งาน
💡 วิธีเปิดง่ายๆ: สร้าง Shortcut บน Desktop ชี้ไปที่ index.html
หรือ Host บน Google Sites / SharePoint ของมหาวิทยาลัยก็ได้
